# WORD / RECALL

既習の英検1級語彙を、30分で確認・復習するオフラインPWA。

公開URL：https://neuralequation.github.io/eiken-vocabulary/

## 使う

1. 公開ページを開き、「CSVを選ぶ」で手元の単語CSVを取り込む。
2. Stage・品詞・カテゴリを選び、30分の「高速確認」を開始。
3. 意味を思い出してから表示し、「思い出せた / 迷った / 思い出せない」で判定。
4. 苦手語は約3分後以降に再確認。一度思い出せたら約10分後以降に再確認。最後5分は、1分以上空いた苦手語を優先。
5. 結果画面から苦手語の復習、CSV出力、全データのバックアップが可能。

30分ですべての項目を確認できることは保証しません。3,010項目を一巡する場合は「全項目を一巡・時間制限なし」を選択してください。25問ごとに範囲をリセットせず、全体の確認済み記録を引き継ぎます。

既習語の確認ツールであり、未確認は未習を意味しません。同じ見出しでも品詞・語義が異なる項目は別に記録します。

## データ

CSVの列：`ステージ,カテゴリ,番号,英単語,日本語訳,発音記号`。UTF-8（BOMあり / なし）、引用符、改行を含むフィールドに対応。

単語CSVや個人の学習記録はこの公開リポジトリに含めません。取り込んだデータはIndexedDBに保存し、外部へ送信しません。同じCSVの再取り込みでは、IDと英語・意味が一致する項目の記録を引き継ぎます。

バックアップJSONには単語と学習記録が含まれます。別端末へ移す際に手元で取り込んでください。バックアップの復元は全置換で、進行中のセッションは復元せず、項目ごとの記録を引き継ぎます。

ブラウザ・URL・端末ごとに保存領域が異なります。ブラウザのデータ削除やストレージの自動解放に備え、バックアップを保存してください。

## 出題と判定

- 高速確認が標準。復習の完了には、時間を空けた選択肢なしの成功が2回必要。
- 4択診断は11秒。取り込みデータ内の同じ品詞から誤答選択肢を生成。同じ英語見出し、同一・部分的に重なる意味を除く。安全な候補が3つ揃わない場合は高速確認に切り替え。
- 自動生成のため、意味の重なりを完全に排除できるとは限りません。元アプリの誤答選択肢は再現していません。
- 正解時は30点＋回答速度0〜4点を内部に記録。公式試験スコアの予測ではありません。速度だけでは苦手と判定しません。
- 復習時刻になった苦手語は確認問題の間に出題し、既習語の確認が止まらないよう復習の連続出題数を制限。
- 時間制限なしの一巡では各項目を一回ずつ出題し、その途中に復習は挟みません。
- タイマーは画面を隠した時・一時停止時に停止。毎回答と学習中5秒ごとに保存。再起動時は停止状態で再開を待ちます。
- Space / Enter：意味表示・次へ、1〜4：回答、Esc：一時停止。

## PWA

HTTPSまたはlocalhostで開いてください。初回接続でアプリ本体をキャッシュし、CSV取り込み後はオフラインでも利用できます。

- Android Chrome：メニュー → アプリをインストール。
- iPhone Safari：共有 → ホーム画面に追加。
- 更新がある場合は「更新を適用」を押すと記録を保存してから更新。新しい版では`sw.js`のキャッシュ名も変更してください。

## 開発・公開

依存パッケージ不要。Node.js 22以上。

```sh
npm test
npm start
```

ローカルURL：`http://127.0.0.1:4173/eiken-vocabulary/`。`file://`で確認しないでください。

GitHub PagesのSourceをGitHub Actionsに設定すると、mainへのpushでテスト後にアプリ本体のみ公開します。単語データを公開する処理はありません。
